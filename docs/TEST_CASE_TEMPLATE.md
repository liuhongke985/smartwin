## 测试用例编写规范

### 测试用例编号格式
`TC-{模块缩写}-{序号}`

示例:
- `TC-DA-001` - 数据资产模块第1个用例
- `TC-AI-001` - AI协同链模块第1个用例
- `TC-AUTH-001` - 认证模块第1个用例

## 功能测试用例模板

### 测试用例基本信息

| 字段 | 内容 |
|------|------|
| **测试用例编号** | TC-XX-NNN |
| **测试用例名称** | 简明描述测试场景 |
| **所属模块** | 模块名称 |
| **测试类型** | 功能测试/边界测试/异常测试 |
| **优先级** | P0/P1/P2/P3 |
| **创建人** | 姓名 |
| **创建日期** | YYYY-MM-DD |
| **关联需求** | 需求编号 |

### 测试用例详情

| 字段 | 内容 |
|------|------|
| **前置条件** | 执行测试前需满足的条件 |
| **测试数据** | 具体的输入数据 |
| **测试步骤** | 逐步操作说明 |
| **预期结果** | 期望的测试结果 |
| **实际结果** | 执行后的实际结果（执行时填写） |
| **测试结论** | 通过/失败/阻塞 |

## 示例测试用例

### TC-DA-001: 创建数据资产 - 正常场景

| 字段 | 内容 |
|------|------|
| **测试用例编号** | TC-DA-001 |
| **测试用例名称** | 数据管理员成功创建新数据资产 |
| **所属模块** | SmartData - 数据资产管理 |
| **测试类型** | 功能测试 |
| **优先级** | P1 |
| **前置条件** | 1. 用户已登录，角色为"数据管理员" <br> 2. 数据资产名称"测试资产001"不存在 |
| **测试数据** | 资产名称: 测试资产001 <br> 分类: 业务数据 <br> 描述: 这是一个测试资产 |
| **测试步骤** | 1. 进入"数据资产管理"页面 <br> 2. 点击"创建数据资产"按钮 <br> 3. 填写资产名称"测试资产001" <br> 4. 选择分类"业务数据" <br> 5. 填写描述 <br> 6. 点击"确认"按钮 |
| **预期结果** | 1. 创建成功提示出现 <br> 2. 资产列表中出现新资产 <br> 3. 资产状态为"活跃" <br> 4. HTTP状态码 201 |
