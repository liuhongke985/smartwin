# DEV-02 Git Workflow Guide

## Branching
- `main`: protected default branch
- `feature/<scope>-<topic>`: feature development
- `hotfix/<topic>`: urgent fixes

## Pull Request Rules
- At least one reviewer approval
- CI workflow must pass
- No direct push to `main`

## Commit Convention
- `feat: ...`
- `fix: ...`
- `docs: ...`
- `chore: ...`
