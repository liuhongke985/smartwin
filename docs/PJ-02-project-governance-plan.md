# PJ-02 Project Governance Plan

## PMC Structure
- Chair: Project Manager
- Members: Backend Lead, Frontend Lead, DevOps Engineer, QA Lead

## Decision & Escalation
1. Working group proposes decision.
2. PMC reviews in scheduled meeting.
3. Blockers > 24h are escalated to Project Manager.
4. Cross-team blockers are escalated to PMC chair.

## Meeting Cadence
- Weekly PMC meeting (60 min)
- Daily standup per sub-team (15 min)
- Detailed Phase 1 schedule and agenda: `docs/PMC_MEETING_SCHEDULE.md`
