# DEV-01 Developer Onboarding Guide

## Checklist
- [ ] Access granted to repository and project board
- [ ] Local tooling installed (Git, Docker, Java/Node/Python as needed)
- [ ] Branch strategy reviewed (`docs/DEV-02-git-workflow-guide.md`)
- [ ] Run local environment with Docker Compose
- [ ] Validate CI pre-check locally

## Local Setup Quick Start
1. `docker compose up -d`
2. Read governance/process docs under `docs/`
3. Open first onboarding issue and complete checklist
