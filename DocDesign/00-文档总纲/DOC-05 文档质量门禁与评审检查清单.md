## 一、文档质量门禁概述

### 1.1 目的

本文档定义「智赢(智数+智链)双平台」项目所有文档的质量门禁标准和评审检查清单，确保每份文档在发布前满足商用软件标准要求。

### 1.2 适用范围

适用于项目全生命周期内所有正式文档（DOC/BIZ/MKT/PJ/REQ/DES/DEV/TC/TR/TST/UI/DEP/OPS/PM/ATT/PRD/ENV/DEL/OPS-BIZ/DRC/SEC-OPS/ECO/MAINT/SUP/COST前缀），共20个目录145份文档。

### 1.3 质量门禁流程

```
文档编写 → 自检(作者) → 同行评审(评审组) → 质量门禁检查(PMO) → 审批(审批人) → 正式发布
```

## 二、文档通用质量门禁检查清单

| 序号 | 检查项 | 通过标准 | 严重性 |

| M-02 | 文档版本号正确 | 采用V主.次.修订格式，与修订记录一致 | 🔴 必须通过 |
| M-03 | 创建日期正确 | YYYY-MM-DD格式 | 🔴 必须通过 |
| M-04 | 最后修订日期正确 | 与实际修订日期一致 | 🔴 必须通过 |
| M-05 | 文档状态正确 | 草稿/评审中/正式发布/已变更/已归档 | 🔴 必须通过 |
| M-06 | 文档负责人已指定 | 填写姓名（角色） | 🔴 必须通过 |
| M-07 | 审批人已指定 | 填写姓名（角色） | 🟡 建议通过 |

### 2.2 内容质量检查

| 序号 | 检查项 | 通过标准 | 严重性 |
|:----:|--------|----------|:------:|

## 四、文档评审流程

### 4.1 评审角色与职责

| 角色 | 职责 | 参与阶段 |
|------|------|----------|
| 文档作者 | 编写文档，自检，根据评审意见修改 | 编写+修改 |
| 同行评审人 | 审查内容准确性、完整性、一致性 | 评审 |
| PMO | 质量门禁检查，确保格式规范 | 门禁 |
| 审批人 | 最终审批，基线锁定 | 审批 |

### 4.2 评审周期要求

| 文档类型 | 评审周期 | 评审人数 |
|----------|:--------:|:--------:|
| 需求文档(BRD/SRS) | 3个工作日 | ≥3人 |
| 设计文档(架构/详细设计) | 3个工作日 | ≥3人 |
| 测试文档(计划/报告) | 2个工作日 | ≥2人 |
| 开发文档(Sprint记录) | 1个工作日 | ≥1人 |
| 运维文档(手册/预案) | 2个工作日 | ≥2人 |
| 管理文档(周报/月报) | 免评审 | PMO审核 |

### 4.3 评审结果处理

| 评审结果 | 处理方式 |
|----------|----------|
| ✅ 通过 | 作者修改minor问题后发布 |
| ⚠️ 有条件通过 | 作者修改major问题，复审后发布 |
| ❌ 不通过 | 作者重新修改，重新组织评审 |
