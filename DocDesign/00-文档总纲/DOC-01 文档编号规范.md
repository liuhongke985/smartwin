## 1. 编号规则总则

### 1.1 编号格式

```
[目录前缀]-[两位序号] [文档中文名称].md
```

### 1.2 示例

```
DOC-00 文档体系总纲说明.md
BIZ-01 商业画布.md
PJ-01  项目章程.md
REQ-02 软件需求规格说明书SRS.md
DES-01 系统架构设计说明书.md
PM-03  Sprint计划.md
OPS-BIZ-01 系统运营总体规划.md
```

### 1.3 编号分配规则

| 规则 | 说明 | 示例 |
|------|------|------|
| 唯一性 | 每份文档有唯一编号，不可重复 | PJ-01 全项目唯一 |
| 连续性 | 同目录下按序号递增，不跳号 | PJ-01, PJ-02, PJ-03... |
| 不可复用 | 已删除文档的编号不可复用 | PJ-05 删除后不可再用 |
| 版本独立 | 编号与版本无关 | PJ-01 V1.0 → V2.0 编号不变 |
| 前缀唯一 | 同一目录可使用多个前缀，但前缀全局唯一 | 06-测试验收使用TC/TR/TST/UI四个前缀 |

## 5. 文档命名补充约定

| 约定 | 说明 | 正确示例 | 错误示例 |
|------|------|----------|----------|
| 使用中文名 | 文档名使用中文 | `PJ-01 项目章程.md` | `PJ-01 Project Charter.md` |
| 英文缩写保留 | 通用英文缩写可保留 | `REQ-02 软件需求规格说明书SRS.md` | `REQ-02 软件需求规格说明书.md` |
| 编号名称间空格 | 编号与名称间一个空格 | `PJ-01 项目章程.md` | `PJ-01项目章程.md` |
| 无特殊字符 | 文件名不含 `/ \ : * ? " < > \|` | `DES-01 系统架构设计说明书.md` | `DES-01 系统/架构.md` |
| 复合前缀用连字符 | 多词前缀使用连字符连接 | `OPS-BIZ-01 系统运营总体规划.md` | `OPSBIZ-01 系统运营总体规划.md` |
| HTML文件同样适用 | HTML格式文档同样遵循编号规范 | `DES-14 系统网站设计方案.html` | `网站设计方案.html` |
| PMO大盘特殊命名 | PMO大盘作为项目管理核心工具，保留特殊命名 | `PMO-DASHBOARD 项目跟踪管理大盘.html` | — |
