## 3. 工单管理流程

### 3.1 工单生命周期

```
创建工单 → 自动分类 → 分配L1 → 初步诊断 → 解决/升级 → 验证 → 关闭
    │           │         │         │           │         │       │
    ↓           ↓         ↓         ↓           ↓         ↓       ↓
  用户提交    AI分类    响应用户   查知识库   L2/L3介入  用户确认  归档
  邮件转工单  优先级    收集信息   尝试解决   开发介入   满意度   统计
  监控转工单  分配      通知      远程协助   补丁修复   评价     改进
```

### 3.2 工单升级规则

| 触发条件 | 升级路径 | 通知方式 |
|---------|---------|---------|
| L1超时未响应 | L1→L2 | 钉钉+邮件 |
| L2超时未响应 | L2→L3 | 钉钉+邮件+电话 |
| L3超时未响应 | L3→L4 | 钉钉+邮件+电话 |
| P0/P1工单 | 直接L3 | 电话+钉钉 |
| 超时未解决 | 升级管理层 | 邮件+电话 |
| 客户投诉 | 升级管理层 | 电话+邮件 |

| 类别 | 子类 | 默认优先级 | 默认分配 |
