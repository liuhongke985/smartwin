## 一、SEO 策略总览

### 1.1 SEO 定位

> **核心目标**：通过搜索引擎优化获取精准 B2B 线索，6 个月内实现月均自然搜索流量 5,000+UV，月均 SEO 线索 80+ 条，转化率 15%。

### 1.2 SEO 策略框架

```
SEO 增长飞轮

┌──→ 技术SEO优化（站点速度/结构化数据/移动适配）
│                    ↓
│              索引覆盖率 ↑
│                    ↓
│    内容SEO（长尾词矩阵/行业深度内容）
│                    ↓
│              关键词排名 ↑
│                    ↓
│    站外SEO（外链建设/品牌提及/社区引流）
│                    ↓
│              域名权重 ↑
│                    ↓
│    流量 → 线索 → 转化 → 案例内容
│                    │
└────────────────────┘
```

### 1.3 目标搜索引擎覆盖

## 三、技术 SEO 优化方案

### 3.1 站点速度优化

| 优化项 | 当前状态 | 目标 | 实施方案 | 优先级 |
|--------|---------|------|---------|:------:|
| FCP (First Contentful Paint) | 1.8s | <1.2s | CDN加速+图片懒加载+CSS内联 | P0 |
| LCP (Largest Contentful Paint) | 2.5s | <2.0s | 首屏数据SSR/预渲染 | P0 |
| TTI (Time to Interactive) | 3.2s | <2.5s | 代码分割+延迟加载非关键JS | P1 |
| CLS (Cumulative Layout Shift) | 0.15 | <0.1 | 图片尺寸预留+字体预加载 | P1 |
| TTFB (Time to First Byte) | 600ms | <300ms | Nginx缓存+Edge渲染 | P0 |

### 3.2 站点结构与索引优化

```
站点结构（SEO 友好层级 ≤3 级）

首页 (/)
├── 产品中心
│   ├── AI模型管理 (/product/model)
│   ├── 成本管控 (/product/cost)
│   ├── 风险预警 (/product/risk)
│   ├── Agent编排 (/product/agent)
│   └── 数据看板 (/product/dashboard)
├── 解决方案
│   ├── 金融行业 (/solution/finance)
│   ├── 政务信创 (/solution/government)
│   ├── 制造业 (/solution/manufacturing)
│   └── 医疗健康 (/solution/healthcare)
├── 技术博客 (/blog)
│   ├── 分类/AI治理 (/blog/category/ai-governance)
│   ├── 分类/信创适配 (/blog/category/xinchuang)
│   └── 分类/前端架构 (/blog/category/frontend)
├── 客户案例 (/cases)
├── 开源项目 (/opensource)
├── 关于我们 (/about)
└── 帮助文档 (/docs)
```

**技术实施清单**：

| 优化项 | 实施方案 | 工时 | 优先级 |
|--------|---------|:----:|:------:|
| sitemap.xml 自动生成 | 每日定时生成 sitemap 并提交百度/Google | 2h | P0 |
| robots.txt 配置 | 允许爬取公开页面，禁止爬取 API/管理后台 | 0.5h | P0 |
| 面包屑结构化数据 | 全站添加 BreadcrumbList JSON-LD | 2h | P0 |
| 产品结构化数据 | 产品页添加 Product JSON-LD | 2h | P1 |
| FAQ 结构化数据 | FAQ 页添加 FAQPage JSON-LD | 2h | P1 |
| 面包屑导航 | 全站统一面包屑导航组件 | 1h | P0 |
| Canonical 标签 | 防止重复内容 | 1h | P0 |
| Open Graph 标签 | 社交分享优化 | 1h | P1 |
| 404 页面优化 | 引导用户回主页+搜索 | 1h | P2 |
| 301 重定向 | 旧URL → 新URL | 1h | P1 |

### 3.3 移动端 SEO 优化

| 优化项 | 实施方案 | 优先级 |
|--------|---------|:------:|
| 响应式设计 | 已在 Sprint 43 实现 responsive.scss | ✅ |
| 移动端速度 | AMP 优先 + 图片 WebP 格式 | P1 |

| 优化项 | 实施方案 | 时间 |

| Google Sitemap | 英文版 sitemap 提交 Google | Month 4 |
| 多语言 canonical | 确保各语言版本正确指向 | Month 4 |

### 4.2 内容生产 SOP

```
内容生产流程（5天周期）

Day 1 (周一): 选题会
├── SEO 数据分析（搜索量/排名/趋势）
├── 行业热点追踪（政策/技术/竞品）
├── 客户问题收集（销售/客服反馈）

├── 结构化标题（H2/H3 层级）
├── 内链 3-5 个相关页面
└── 配图 3-5 张（含 alt 属性）

Day 4 (周四): SEO 优化审校
├── TDK 优化（Title/Description/Keywords）
├── 首段包含目标关键词
├── 图片 alt 属性检查
├── 内链/外链检查
└── 可读性评分（目标 >60）

Day 5 (周五): 发布与分发
├── 官网博客发布
├── 掘金/知乎/CSDN 分发
├── 公众号同步推送
├── 社群分享
└── 社交媒体预告
```

### 4.3 内容质量标准

| 质量维度 | 标准 | 检查工具 |
|---------|------|---------|
| 字数 | 博客 ≥2000 字，方案页 ≥3000 字 | Word Count |
| 关键词密度 | 主关键词 2-3%，长尾词 1-2% | Yoast SEO |
| 可读性 | Flesch Score >60 | 在线可读性检测 |
| 内链数量 | 每篇 ≥3 个内链 | 手动检查 |
| 外链数量 | 每篇 ≤3 个权威外链 | 手动检查 |
| 图片 | 每篇 ≥3 张，含 alt 属性 | 手动检查 |
| 结构化 | H2/H3 层级清晰，含列表/表格 | 手动检查 |
| 原创度 | >85% 原创内容 | Copyscape |
| 更新频率 | 旧文章每季度更新一次 | CMS 提醒 |
