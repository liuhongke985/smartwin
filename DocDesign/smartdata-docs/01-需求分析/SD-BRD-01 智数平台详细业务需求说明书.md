## 1. 业务背景与市场分析

### 1.1 行业背景

当前企业数据治理面临三大核心挑战：

1. **数据资产化需求迫切**：国家《数据安全法》《个人信息保护法》及"数据二十条"政策推动下，企业数据资产入表、数据要素流通成为刚需。2025年中国数据要素市场规模预计突破1,200亿元，年复合增长率超过25%。
2. **AI驱动数据治理变革**：传统数据治理依赖人工规则配置，效率低、覆盖面窄。大模型技术为自动化元数据标注、智能质量检测、自然语言数据搜索提供了全新可能。
3. **信创合规要求升级**：党政机关及国央企信创替代进入深水区，要求数据治理平台全面适配国产芯片、操作系统、数据库及国密算法。

### 1.2 竞争格局

| 竞品 | 优势 | 劣势 |
|------|------|------|
| 阿里 DataWorks | 生态完整、云原生 | 私有化部署弱、信创支持不足 |
| 腾讯 WeData | 与腾讯云深度绑定 | 数据治理功能深度不够 |
| 网易数帆 | 轻量级、易部署 | 功能覆盖面有限 |
| 华为 DataArts | 全栈信创、政企经验 | AI能力较弱、价格高 |
| 亿信华辰 PetaBase | 数据治理专业 | 架构较老、AI融合不足 |

**智数差异化优势**：AI原生架构 + 全栈信创 + 双平台协同（智链AI运营+智数数据治理）

### 1.3 市场机会

- **目标市场**：年营收5亿以上的中大型企业、政府机构、金融机构
- **市场规模**：国内数据治理平台市场约200亿元/年，年增速20%+
- **切入机会**：信创替代窗口期（2024-2027），大量政府/国企需替换Oracle/SAS等国外数据治理工具

## 2. 产品定位与愿景

### 2.1 产品定位

智数（SmartData）是**AI原生的企业级数据治理平台**，帮助企业实现"数据可见、数据可懂、数据可信、数据可用"四大核心目标。

### 2.2 产品愿景

> 让每一个企业都能像互联网巨头一样高效治理和利用数据资产。

### 2.3 核心价值主张

| 价值维度 | 描述 | 量化指标 |
|---------|------|---------|
| AI驱动 | 大模型辅助元数据标注、质量检测、数据搜索 | 元数据标注效率提升10倍 |
| 全栈信创 | 适配国产CPU/OS/DB/国密算法 | 100%信创清单覆盖 |
| 数据资产化 | 完整的数据资产目录与估值体系 | 资产编目覆盖率≥95% |
| 质量自动化 | 规则模板+AI检测，自动化质量巡检 | 质量检测自动化率≥80% |
| 血缘追踪 | 字段级血缘采集与影响分析 | 血缘覆盖率≥90% |

### 2.4 与智链平台的关系

智数与智链共同构成智赢（SmartWin）一体化平台：
- **智数**：专注数据治理——数据资产、元数据、质量、标准、血缘、主数据、生命周期、数据服务
- **智链**：专注AI运营——模型管理、智能体编排、成本管控、风险监控
- **协同点**：智数为智链提供高质量训练数据；智链为智数提供AI增强能力（智能搜索、异常检测）

### 5.2 核心业务流程

#### 5.2.1 数据资产化管理流程

```
数据源接入 → 自动资产发现 → 元数据采集 → 资产编目 → 质量评估 → 标准映射 → 血缘建立 → 资产发布 → 数据服务
```

#### 5.2.2 数据质量治理闭环

```
质量规则定义 → 自动化检测 → 质量报告生成 → 问题工单派发 → 修复跟踪 → 复检验证 → 质量评分更新
```

```
标准定义 → 标准审批 → 标准映射(关联元数据) → 落地检查 → 合规报告 → 持续监控
```

## 6. 功能域详细需求

### 6.1 数据资产管理 (DAM)

#### 6.1.1 业务背景

企业数据散落在数十甚至上百个系统中，缺乏统一目录。数据消费者难以发现和信任数据，数据价值无法量化。

#### 6.1.2 业务需求清单

| 需求ID | 需求名称 | 优先级 | 业务描述 | 验收标准 |
|--------|---------|:------:|---------|---------|
| DAM-B01 | 数据资产注册 | P0 | 支持手动录入和自动发现两种方式注册数据资产 | 资产注册成功率100%，含名称/描述/来源/分类/标签 |
| DAM-B02 | 多级目录编目 | P0 | 支持无限层级的业务分类目录树 | 目录树支持拖拽编目，按目录节点权限控制 |
| DAM-B03 | 全文检索 | P0 | 基于ES的资产全文搜索，支持模糊/精确/组合查询 | 搜索响应≤500ms，支持中英文分词 |
| DAM-B04 | 多维筛选 | P0 | 按分类/标签/数据源/质量评分/更新时间筛选 | 支持多条件组合筛选 |
| DAM-B05 | AI问答搜索 | P1 | 基于大模型的自然语言数据资产查询 | 支持自然语言提问返回资产推荐 |
| DAM-B06 | 资产评分 | P1 | 多维度评分（完整性/准确性/及时性/一致性/唯一性） | 评分模型可配置，自动计算 |
| DAM-B07 | 资产估值 | P2 | 基于使用频次/业务价值评估数据资产价值 | 估值模型可配置 |
| DAM-B08 | 资产审批流程 | P1 | 新增/变更资产需经审批后发布 | 支持多级审批，可配置审批流 |
| DAM-B09 | 资产批量导入 | P1 | Excel模板批量导入资产信息 | 支持模板下载、数据校验、导入报告 |
| DAM-B10 | 资产变更追踪 | P1 | 记录资产变更历史，支持版本对比 | 变更日志完整，支持可视化对比 |
| DAM-B11 | 治理健康分模型 | P1 | 多维度量化评估数据治理健康度（存储/计算/质量/安全/标准） | 健康分自动计算，支持趋势分析 |
| DAM-B12 | 数据资产估值模型 | P2 | 基于使用频次/业务价值/数据质量评估数据资产价值 | 估值模型可配置，支持ROI分析 |

#### 6.1.3 业务规则

- 资产名称在同目录下唯一
- 资产分类遵循企业数据分类标准
- 资产发布前必须完成元数据采集和质量基线检测
- 资产下架需进行影响分析，确认无下游依赖

| DQ-B05 | 质量报告 | P0 | 生成质量评分卡、趋势图、问题清单 | 支持PDF/Excel导出 |

| DQ-B07 | AI质量检测 | P1 | 大模型辅助异常检测和数据漂移识别 | 异常检出率≥85% |
| DQ-B08 | 质量修复建议 | P2 | AI生成质量修复建议 | 建议可采纳率≥60% |

|--------|---------|:------:|---------|---------|
