## 2. 数据探查与数据画像产品设计

### 2.1 功能架构

```
数据探查模块
├── 探查任务管理
│   ├── 手动探查（资产详情页触发）
```

### 2.3 交互流程

#### 探查发起流程

```
用户进入资产详情页
    │
    ├── 自动展示最近一次探查结果（如有）
    │
    ├── 用户点击"发起探查"
    │   ├── 弹出探查配置弹窗
    │   │   ├── 探查范围: ○全表 ○抽样(1%/5%/10%/20%)
    │   │   ├── 异常检测: ☑统计异常 ☑模式异常 ☐空值突增
    │   │   ├── AI解读: ☑启用
    │   │   └── 数据采样: ☑启用（默认100行，脱敏）
    │   ├── 确认后提交探查任务
    │   └── 显示进度条（采集→统计→检测→AI解读→完成）
    │
    └── 探查完成后自动刷新画像数据
```

#### 定时探查配置流程

```
用户点击"定时配置"
    ├── 选择频率: ○每日 ○每周 ○每月 ○自定义Cron
    ├── 选择时间: [下拉选择]
    ├── 选择范围: [同手动配置]
    ├── 通知设置: ☑探查完成通知 ☑异常告警通知
    └── 保存策略
```

## 10. 交互设计规范

### 10.1 通用交互规范

| 规范项 | 规则 |
|--------|------|
| 加载状态 | 数据加载时显示骨架屏或加载动画，超过3秒显示进度 |
| 空状态 | 无数据时展示空状态插画和引导文案 |
| 错误状态 | 错误信息清晰提示，提供重试操作 |
| 操作反馈 | 所有操作需有即时反馈（Toast/消息提示） |
| 确认操作 | 删除/停用等不可逆操作需二次确认 |
| 批量操作 | 列表页支持多选+批量操作 |
| 搜索防抖 | 搜索输入框300ms防抖 |
| 表格分页 | 默认每页20条，支持50/100切换 |
| 表格排序 | 列标题点击排序，支持升序/降序 |
| 表格筛选 | 支持列级筛选，筛选条件持久化 |
