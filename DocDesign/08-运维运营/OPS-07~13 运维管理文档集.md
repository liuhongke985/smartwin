# OPS-07 变更管理流程

## 一、变更分类

| 变更类型 | 定义 | 审批 | 停机窗口 |
|---------|------|------|:--------:|
| 标准变更 | 预定义的低风险变更 | 预审批 | 无需 |
| 普通变更 | 需评估影响的变更 | 变更委员会 | 可选 |
| 紧急变更 | 紧急修复 | 运维负责人 | 需评估 |

## 二、变更流程

```
提交变更申请 → 影响评估 → CAB审批 → 制定计划 → 实施变更 → 验证 → 关闭
```

## 三、变更回滚

| 变更类型 | 回滚方式 | 回滚时间 |
|---------|---------|:--------:|
| 代码变更 | 蓝绿回滚 | ≤5分钟 |
| 数据库变更 | Flyway回滚 | ≤30分钟 |
| 配置变更 | 配置回滚 | ≤1分钟 |
| 基础设施 | 镜像回滚 | ≤10分钟 |

# OPS-09 CMDB配置管理

## 一、配置项分类

| CI类型 | 示例 | 关键属性 |
|--------|------|---------|
| 服务器 | K8s节点 | IP/CPU/内存/磁盘/位置 |
| 服务 | 微服务 | 版本/实例数/依赖/端口 |
| 数据库 | PostgreSQL | 版本/主从/连接串/容量 |
| 中间件 | Kafka/Redis | 集群/Topic/分区 |
| 网络 | 负载均衡/Firewall | VIP/规则/端口 |
| 证书 | TLS证书 | 域名/有效期/CA |

## 二、配置项关系

```
应用 → 依赖 → 服务 → 部署在 → 服务器 → 连接 → 网络
               ↓
            使用 → 数据库
            使用 → 中间件
```

# OPS-12 备份恢复方案

## 一、备份策略

| 数据类型 | 备份方式 | 频率 | 保留 | 验证 |
|---------|---------|------|------|------|
| 数据库(主) | pg_dump全量+WAL增量 | 每日全量+实时增量 | 30天 | 每周恢复测试 |
| 数据库(审计) | pg_dump全量 | 每日 | 永久 | 每月验证 |
| Neo4j | 全量备份 | 每日 | 14天 | 每周验证 |
| Elasticsearch | Snapshot | 每日 | 14天 | 每月验证 |
| 配置数据 | Git版本控制 | 实时 | 永久 | CI/CD验证 |
| 文件存储 | MinIO版本化 | 实时 | 90天 | 自动校验 |

## 二、恢复目标

| 场景 | RTO | RPO | 恢复方式 |
|------|:---:|:---:|---------|
| 单表误删 | ≤15分钟 | ≤5分钟 | PITR恢复 |
| 数据库故障 | ≤30分钟 | ≤1分钟 | 主从切换 |
| 灾难恢复 | ≤2小时 | ≤15分钟 | 异地备份恢复 |
