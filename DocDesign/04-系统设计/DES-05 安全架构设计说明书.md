## 2. 身份认证体系

### 2.1 JWT认证流程

```
1. 用户提交用户名+密码 → auth-service
2. auth-service验证凭据 → 生成Access Token(2h) + Refresh Token(7d)
3. Token存储Redis(key=userId, value=tokenInfo)
4. 客户端存储Token(localStorage)
5. 后续请求携带Authorization: Bearer <accessToken>
6. 网关JwtAuthFilter校验Token → 注入用户信息到Header
7. Token过期 → 使用Refresh Token刷新
8. 用户登出 → Redis删除Token(主动失效)
```

### 2.2 Token结构

```json
{
  "header": { "alg": "HS256", "typ": "JWT" },
  "payload": {
    "sub": "userId",
    "username": "admin",
    "roles": ["SUPER_ADMIN"],
    "permissions": ["model:create", "model:read"],
    "iat": 1720000000,
    "exp": 1720007200
  }
}
```

### 2.3 密码安全

| 策略 | 说明 |
|------|------|
| 加密算法 | BCrypt(cost=10) |
| 密码复杂度 | ≥8位，含大小写+数字+特殊字符 |
| 密码锁定 | 连续5次失败锁定30分钟 |
| 密码过期 | 90天强制更换(可选) |
| 密码历史 | 不可重复最近5次密码 |

## 3. 访问控制体系

### 3.1 RBAC权限模型

```
用户(User) → 角色(Role) → 权限(Permission)
    │              │              │
 sys_user    sys_role      sys_permission
    │              │              │
    └──sys_user_role──┘              │
                     └──sys_role_permission──┘
```

### 3.2 权限粒度

| 层级 | 粒度 | 示例 |
|------|------|------|
| 菜单级 | 控制菜单显示 | `model:menu` |
| 按钮级 | 控制按钮显示 | `model:create` |
| API级 | 控制接口访问 | `POST /api/intelchain/models` |
| 数据级 | 控制数据范围 | 仅查看本部门数据 |

### 3.3 权限注解

```java
@RequiresPermission("model:create")    // 需要指定权限
@RequiresRole("ADMIN")                  // 需要指定角色
@RequiresAnyPermission({"model:read", "model:export"})  // 满足任一权限
```

## 4. 国密算法集成

### 4.1 算法使用场景

| 算法 | 类型 | 使用场景 |
|------|------|----------|
| SM2 | 非对称加密 | 数字签名、密钥交换 |
| SM3 | 哈希摘要 | 数据完整性校验、密码哈希 |
| SM4 | 对称加密 | 数据加密存储、传输加密 |

### 4.2 CryptoFacade统一门面

```java
// 统一国密服务门面
public interface CryptoService {
    // SM2 - 非对称
    String sm2Encrypt(String plaintext, String publicKey);
    String sm2Decrypt(String ciphertext, String privateKey);
    String sm2Sign(String data, String privateKey);
    boolean sm2Verify(String data, String signature, String publicKey);

    // SM3 - 哈希
    String sm3Hash(String data);

    // SM4 - 对称
    String sm4Encrypt(String plaintext, String key);
    String sm4Decrypt(String ciphertext, String key);
}
```

### 4.3 密钥管理

| 密钥类型 | 存储位置 | 轮换周期 |
|----------|----------|:--------:|
| SM2密钥对 | 密钥管理服务(加密存储) | 1年 |
| SM4对称密钥 | 密钥管理服务(加密存储) | 6个月 |
| JWT签名密钥 | 配置中心(Nacos) | 3个月 |
| API密钥 | 数据库(SM4加密) | 按需 |

> 详见 [DES-09 信创全栈适配与国密算法设计方案](./DES-09%20信创全栈适配与国密算法设计方案.md)

## 5. 数据安全治理

### 5.1 数据分级分类

| 等级 | 说明 | 示例 | 保护措施 |
|:----:|------|------|----------|
| L1 | 公开数据 | 产品公告 | 无特殊保护 |
| L2 | 内部数据 | 内部报告 | 登录可见 |
| L3 | 机密数据 | 用户信息 | 权限控制+脱敏 |
| L4 | 绝密数据 | 密钥/凭证 | 加密存储+审计 |

### 5.2 数据脱敏

| 数据类型 | 脱敏规则 | 示例 |
|----------|----------|------|
| 手机号 | 保留前3后4 | 138****8888 |
| 身份证号 | 保留前6后4 | 110101********1234 |
| 邮箱 | 保留前2后缀 | ad****@example.com |
| 银行卡号 | 保留后4 | ****8888 |
| API密钥 | 保留前4后4 | sk-x****8888 |

### 5.3 传输安全

| 措施 | 说明 |
|------|------|
| HTTPS | 全站TLS 1.3 |
| 证书 | SM2国密证书(信创环境) |
| HSTS | 强制HTTPS |
| CORS | 白名单域名 |

## 6. API安全

### 6.1 网关层防护

| 防护措施 | 说明 |
|----------|------|
| JWT认证 | 所有API必须携带有效Token |
| 限流 | 基于IP/用户的令牌桶限流 |
| IP黑白名单 | 可配置IP访问策略 |
| 请求体大小限制 | 最大10MB |
| 请求超时 | 30s超时 |

### 6.2 API输入校验

| 校验类型 | 说明 |
|----------|------|
| 参数校验 | JSR-303 Bean Validation |
| SQL注入防护 | MyBatis参数化查询 |
| XSS防护 | 输入过滤+输出编码 |
| CSRF防护 | Token+SameSite Cookie |
| 文件上传 | 类型白名单+大小限制+病毒扫描 |

## 9. 安全应急响应

### 9.1 安全事件分级

| 等级 | 说明 | 响应时间 |
|:----:|------|:--------:|
| P0 | 系统被入侵/数据泄露 | 15分钟 |
| P1 | 漏洞被利用/权限被绕过 | 30分钟 |
| P2 | 漏洞发现但未被利用 | 4小时 |
| P3 | 潜在安全风险 | 24小时 |

### 9.2 应急响应流程

```
安全事件发现 → 事件定级 → 应急启动 → 影响评估 → 遏制隔离 → 根因分析 → 恢复服务 → 复盘改进
```
