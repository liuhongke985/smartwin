## 1. 质量管理概述

### 1.1 质量目标

| 质量维度 | 目标 | 度量方式 |
|----------|------|----------|
| 功能质量 | 验收通过率≥95% | UAT报告 |
| 代码质量 | 单测覆盖>70%，重复<5% | SonarQube |
| 性能质量 | API P95<500ms | 性能测试 |
| 安全质量 | 等保三级通过 | 测评报告 |
| 交付质量 | 里程碑偏差<2周 | 进度跟踪 |
| 文档质量 | 文档及时更新率≥95% | 文档审计 |

### 1.2 质量管理流程

```
质量计划 → 质量保证(QA) → 质量控制(QC) → 质量改进
              ↑                │
              └── 反馈 ───────┘
```

## 2. 代码质量标准

### 2.1 后端代码规范

| 规范项 | 标准 | 工具 |
|--------|------|------|
| 编码规范 | 阿里巴巴Java开发手册 | Checkstyle |
| 命名规范 | 类名PascalCase/方法camelCase | Checkstyle |
| 注释规范 | 类/方法/字段必须有注释 | Checkstyle |
| 异常处理 | 统一异常处理+业务异常码 | Code Review |
| 日志规范 | SLF4J+合理级别+上下文 | Code Review |
| SQL规范 | MyBatis-Plus+参数化查询 | Code Review |
| 安全规范 | 无SQL注入/XSS/硬编码密钥 | SonarQube+ZAP |

### 2.2 前端代码规范

| 规范项 | 标准 | 工具 |
|--------|------|------|
| 编码规范 | Vue官方风格指南 | ESLint+Prettier |
| 类型安全 | TypeScript strict模式 | vue-tsc |
| 组件规范 | 单文件组件+Composition API | ESLint |
| 命名规范 | 组件PascalCase/变量camelCase | ESLint |
| 样式规范 | Scoped CSS+CSS变量 | Stylelint |
| 可访问性 | WCAG 2.1 AA | axe-core |

### 2.3 质量门禁

所有代码合入主分支前必须通过以下门禁：

| 门禁 | 标准 | 阻断级别 |
|------|------|:--------:|
| 编译通过 | 0 Error | 🔴 阻断 |
| 单元测试 | 覆盖率>70% + 0 Failure | 🔴 阻断 |
| 静态分析 | 0 Blocker + 0 Critical | 🔴 阻断 |
| 代码重复 | < 5% | 🟡 警告 |
| 代码评审 | 2人Approve | 🔴 阻断 |
| API文档 | 100%接口有注解 | 🟡 警告 |

## 3. 测试质量标准

### 3.1 测试分层

| 测试层 | 范围 | 工具 | 覆盖目标 | 执行频率 |
|--------|------|------|:--------:|:--------:|
| 单元测试 | 方法/类级 | JUnit5+Mockito/Vitest | >70% | 每次提交 |
| 集成测试 | 服务级 | SpringBootTest | 关键路径 | 每日CI |
| 接口测试 | API级 | REST Assured/Postman | 100%API | 每日CI |
| E2E测试 | 用户路径 | Playwright | 核心流程 | 每周 |
| 性能测试 | 并发/响应 | k6/JMeter | P95<500ms | 每里程碑 |
| 安全测试 | 漏洞扫描 | OWASP ZAP | 0高危 | 发布前 |

### 3.2 缺陷管理

#### 缺陷等级

| 等级 | 定义 | 修复时限 |
|:----:|------|:--------:|
| P0-致命 | 系统崩溃/数据丢失/安全漏洞 | 4小时内 |
| P1-严重 | 核心功能不可用 | 1个工作日 |
| P2-一般 | 非核心功能异常 | 3个工作日 |
| P3-轻微 | UI/文案/体验问题 | 下个Sprint |

#### 缺陷密度标准

| 模块 | 缺陷密度标准 | 度量 |
|------|:----------:|------|
| 共享底座 | < 1.5个/KLOC | SonarQube |
| 智链服务 | < 2.0个/KLOC | SonarQube |
| 智赢服务 | < 2.0个/KLOC | SonarQube |
| 前端 | < 2.5个/KLOC | SonarQube |

#### 发布质量门禁

| 门禁 | 标准 | 阻断 |
|------|------|:----:|
| P0缺陷 | 0个 | 🔴 |
| P1缺陷 | 0个 | 🔴 |
| P2缺陷 | < 5个 | 🟡 |
| 单测覆盖 | > 70% | 🔴 |
| E2E通过率 | > 95% | 🔴 |
| 安全扫描 | 0高危 | 🔴 |
| 性能测试 | P95 < 500ms | 🔴 |
