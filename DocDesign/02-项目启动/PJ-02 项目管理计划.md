## 1. 项目管理概述

### 1.1 项目管理方法论

本项目采用**混合敏捷（Hybrid Agile）**管理方法：

| 层面 | 方法 | 说明 |
|------|------|------|
| 整体规划 | 瀑布式 | 12个月总体计划、5个阶段、5个里程碑 |
| 迭代执行 | Scrum | 2周一个Sprint，共26个Sprint |
| 需求管理 | Kanban | 需求池管理、优先级排序、持续流转 |
| 质量管理 | DevOps | CI/CD、自动化测试、持续集成 |
| 风险管理 | PMBOK | 风险登记册、定期评审、应对策略 |

### 1.2 管理计划组成

本项目管理计划由以下子计划组成：

| 子计划 | 文档编号 | 说明 |
|--------|----------|------|
| 范围管理 | PJ-03 | 项目范围定义与控制 |
| 进度管理 | PJ-04 | 时间规划与跟踪 |
| 成本管理 | PJ-05 | 预算编制与控制 |
| 风险管理 | PJ-06 | 风险识别与应对 |
| 沟通管理 | PJ-07 | 沟通机制与报告 |
| 质量管理 | PJ-08 | 质量标准与保证 |
| 治理章程 | PJ-11 | 决策机制与治理结构 |

## 3. 进度管理

### 3.1 进度跟踪机制

| 跟踪活动 | 频率 | 负责人 | 产出 |
|----------|:----:|--------|------|
| 每日站会 | 每日 | Scrum Master | 站会纪要 |
| 周度跟踪 | 每周 | 项目经理 | 项目周报(PM-01) |
| 月度跟踪 | 每月 | 项目经理 | 项目月报(PM-02) |
| Sprint跟踪 | 每Sprint | Scrum Master | Sprint燃尽图 |
| 里程碑跟踪 | 每里程碑 | 项目经理 | 里程碑报告(PM-05) |

### 3.2 进度偏差管理

| 偏差范围 | 处理方式 | 审批人 |
|:--------:|----------|--------|
| < 5% | 项目组内部调整 | 项目经理 |
| 5%-10% | 分析原因、调整计划 | 项目总监 |
| 10%-20% | 启动应急预案、资源调配 | 项目总监 |
| > 20% | 重大变更、上报指导委员会 | 指导委员会 |

### 3.3 关键路径

```
共享底座开发(M1-M3) → 智链业务服务(M4-M5) → 智链前端+AI(M6-M7)
    → 智链V1.0发布(M7) → 智赢核心服务(M8-M9) → 智赢扩展+前端(M10-M12)
    → 智赢V1.0发布(M12)
```

## 4. 成本管理

### 4.1 预算控制

| 控制项 | 说明 | 预警阈值 |

| 月度支出 | 每月实际vs预算对比 | 偏差>10%预警 |

## 8. 变更管理

### 8.1 变更控制流程

```
1. 变更申请 → 提交《变更请求表》至PMO
2. 影响分析 → PMO评估范围/进度/成本影响
3. 变更评审 → 变更控制委员会(CCB)评审
4. 审批决策 → 按权限审批
5. 实施变更 → 执行变更并更新基线
6. 验证关闭 → 验证变更结果，关闭变更
```

### 8.2 变更审批权限

| 变更类型 | 审批人 | 时限 |
|----------|--------|:----:|
| 小型变更（<2人日） | 项目经理 | 1个工作日 |
| 中型变更（2-10人日） | 项目总监 | 3个工作日 |
| 大型变更（>10人日） | 指导委员会 | 5个工作日 |
| 紧急变更 | 项目总监 | 即时 |

### 8.3 变更记录

所有变更记录在 [PM-07 变更请求日志.md](../08-项目管理/PM-07%20变更请求日志.md) 中跟踪。
