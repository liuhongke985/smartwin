### 1.2 资源配置原则

| 原则 | 说明 |
|------|------|
| 共享优先 | 共享底座团队先行，为两条产品线提供基础 |
| 智链先行 | 智链产品线先于智数产品线启动 |
| 前后端并行 | 后端API就绪后前端立即介入 |
| 关键路径保障 | 关键路径上的任务优先分配高级资源 |
| AB角备份 | 核心岗位设置AB角，降低单点风险 |

## 4. 资源冲突管理

### 4.1 潜在冲突

| 冲突场景 | 时间 | 影响 | 解决方案 |
|----------|:----:|------|----------|
| 共享底座与智链开发抢人 | M2-M3 | 共享底座延期 | 共享底座优先、智链错峰启动 |
| 智链前端与智数后端并行 | M6-M8 | 前端资源紧张 | 外包补充前端、智数后端延后1Sprint |
| 双前端并行开发 | M11 | 前端资源严重不足 | 智链前端收尾后转智数、外包补充 |

### 4.2 资源调配流程

```
冲突识别 → 影响评估 → 调配方案 → 项目经理审批 → 执行调配 → 效果跟踪
```
