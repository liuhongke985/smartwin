## 1. 治理结构

### 1.1 三层治理模型

```
┌─────────────────────────────────┐
│     项目指导委员会 (战略层)       │
│  CTO + 高管 + 财务负责人         │
│  职责: 战略决策、预算审批、重大变更│
│  频率: 每季度                    │
└───────────────┬─────────────────┘
                │
┌───────────────┴─────────────────┐
│     项目管理层 (管理层)           │
│  项目总监 + 项目经理 + PMO       │
│  职责: 计划审批、风险决策、资源调配│
│  频率: 每月                      │
└───────────────┬─────────────────┘
                │
┌───────────────┴─────────────────┐
│     项目执行层 (执行层)           │
│  各组长 + 开发/测试/DevOps        │
│  职责: 日常执行、技术决策、质量保障│
│  频率: 每周                      │
└─────────────────────────────────┘
```

### 1.2 变更控制委员会（CCB）

| 成员 | 角色 |
|------|------|
| 项目总监 | CCB主席 |
| 项目经理 | CCB秘书 |
| 架构师 | 技术评估 |
| 产品经理 | 需求评估 |
| 测试Lead | 质量评估 |

## 2. 决策权限矩阵

### 2.1 RACI矩阵

R=负责 A=审批 C=咨询 I=知会

| 决策项 | 项目组 | 项目经理 | 项目总监 | 指导委员会 |
|--------|:------:|:--------:|:--------:|:----------:|
| 日常任务分配 | R/A | I | — | — |
| 技术方案选择 | R | A | C | — |
| 范围变更(小) | C | R/A | I | — |
| 范围变更(大) | C | R | A | I |
| 进度调整(<5%) | C | R/A | I | — |
| 进度调整(>10%) | C | C | R/A | I |
| 预算调整(<10%) | — | R | A | I |
| 预算调整(>10%) | — | C | R | A |
| 人员招聘 | C | R | A | I |
| 人员辞退 | — | C | R/A | I |
| 技术栈变更 | C | C | R | A |
| 里程碑调整 | C | C | R/A | I |
| 项目暂停/终止 | — | — | C | R/A |

### 2.2 决策时限

| 决策类型 | 决策人 | 审批时限 | 升级路径 |
|----------|--------|:--------:|----------|
| 技术决策 | 架构师 | 2个工作日 | →项目总监 |
| 范围变更(小) | 项目经理 | 1个工作日 | →项目总监 |
| 范围变更(大) | 项目总监 | 3个工作日 | →指导委员会 |
| 预算调整 | 项目总监 | 5个工作日 | →指导委员会 |
| 紧急决策 | 项目总监 | 即时 | — |
| 人员调配 | 项目经理 | 2个工作日 | →项目总监 |

## 3. 会议治理

### 3.1 治理会议体系

| 会议 | 频率 | 主席 | 参与人 | 决策权限 |
|------|:----:|------|--------|----------|
| 指导委员会 | 每季 | CTO | 高管+总监 | 战略级决策 |
| 月度治理 | 每月 | 项目总监 | 经理+组长 | 管理级决策 |
| 周度治理 | 每周 | 项目经理 | 各组长 | 执行级决策 |
| CCB评审 | 按需 | 项目总监 | CCB成员 | 变更决策 |
| 技术评审 | 按需 | 架构师 | 开发组 | 技术决策 |

### 3.2 决策记录

所有重要决策记录在 [PM-09 决策日志.md](../08-项目管理/PM-09%20决策日志.md) 中，包含：
