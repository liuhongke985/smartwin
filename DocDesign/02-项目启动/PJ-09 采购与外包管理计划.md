## 1. 采购管理概述

### 1.1 采购目标

确保项目所需的基础设施、软件License、第三方服务和外包资源按时、按质、按预算到位，支撑项目12个月开发周期内的全部采购需求。

### 1.2 采购原则

| 原则 | 说明 |
|------|------|
| 合规性 | 遵循公司采购流程和审批权限 |
| 性价比 | 在满足需求的前提下选择最优性价比 |
| 信创优先 | 优先采购国产化产品和服务 |
| 风险控制 | 关键采购项需有备选供应商 |
| 时效性 | 采购计划提前制定，避免阻塞开发 |

## 3. 采购流程

### 3.1 采购审批流程

```
需求提出 → 采购申请 → 预算审核 → 供应商比选 → 合同审批 → 签约采购 → 验收入库
   │           │          │           │           │          │          │
 需求部门    PMO      财务负责人   采购经理    项目总监   法务/财务   需求部门
```

### 3.2 审批权限

| 采购金额 | 审批人 | 审批时限 |
|:--------:|--------|:--------:|
| < 5万元 | 项目经理 | 2个工作日 |
| 5-20万元 | 项目总监 | 3个工作日 |
| 20-50万元 | 项目总监+财务总监 | 5个工作日 |
| > 50万元 | 指导委员会 | 7个工作日 |

### 3.3 供应商管理

| 管理项 | 说明 |
|--------|------|
| 供应商准入 | 营业执照+资质审查+信用评估 |
| 比选规则 | 至少3家报价（单一来源除外） |
| 合同管理 | 标准合同模板+法务审核 |
| 验收标准 | 合同约定验收标准+测试报告 |
| 供应商评价 | 季度评价+年度评审 |
