## 二、V2.1 P0/P1修复清单 (12项已完成)

### 2.1 LoginView.vue 硬编码凭据移除
- **问题:** 表单预填 `username: isDev ? 'admin' : ''`，忘记密码使用原生 `prompt()`
- **修复:**
  - 移除表单预填逻辑，改为空值初始化
  - 开发环境提示改用 `VITE_DEV_HINT` 环境变量
  - 忘记密码改为 Teleport 弹窗 + 邮箱验证 + `authApi.requestPasswordReset`
  - 成功提示改用 Toast
- **影响文件:** `LoginView.vue`, `api/auth.ts`
- **修复时间:** 2026-07-09

### 2.2 PermissionManageView.vue 原生confirm()替换
- **问题:** 删除操作使用 `confirm()`，表单无验证
- **修复:**
  - 引入 ConfirmDialog 组件替代 `confirm()`
  - 引入 useFormValidation + rules 进行表单验证（permName/permCode）
  - 引入 useToast 替代 console.error
  - closeModal 时重置验证状态
- **影响文件:** `PermissionManageView.vue`

### 2.3 路由守卫权限校验 + 菜单动态过滤
- **问题:** 路由守卫仅检查 `isLoggedIn`，菜单对所有用户全量展示
- **修复:**
  - `beforeEach` 增加 `to.meta.permission` 权限码校验
  - 系统管理7条路由配置权限码 (`system:user:list` 等)
  - 模型管理2条路由配置权限码 (`model:list`, `model:create`)
  - 导出 `filterMenuByPermission()` 函数
  - MainLayout 使用 `computed` 动态过滤菜单
- **影响文件:** `router/index.ts`, `MainLayout.vue`

### 2.4 AppChatView.vue 对话界面全面重写
- **问题:** 仅71行基础对话，无Markdown/流式/复制/历史
- **修复:** 完全重写为300+行
  - Markdown渲染（代码块/行内代码/粗体/标题/列表）
  - 流式逐字输出模拟
  - 消息复制（Clipboard API + Toast）
  - 重新生成（回溯用户消息重新请求）
  - 对话历史侧栏（新建/切换会话）
  - 导出对话为Markdown文件
  - 欢迎页 + 快捷建议词
  - 打字动画指示器
  - 文件上传入口
  - 字数统计
  - 响应式设计（移动端隐藏侧栏）
- **影响文件:** `AppChatView.vue`

### 2.5 AgentFlowView.vue alert()替换
- **问题:** 保存成功使用 `alert()`
- **修复:** 改用 `useToast().success()` 
- **影响文件:** `AgentFlowView.vue`

### 2.6 StatusPageView.vue alert()替换
- **问题:** 订阅成功使用 `alert()`，无邮箱验证
- **修复:** 改用 `useToast()`，增加邮箱格式验证
- **影响文件:** `StatusPageView.vue`

### 2.7 auth API 扩展
- **修复:** 新增 `requestPasswordReset(email)` 和 `resetPassword(token, newPassword)` 接口
- **影响文件:** `api/auth.ts`

### 2.8 全站原生交互清除验证
- **结果:** 全站无 `alert()` / `prompt()` / `confirm()` 残留
- **验证方法:** ripgrep 全量搜索确认

### 2.9 AppCreateView.vue 模型选择改为API下拉
- **问题:** `modelId` 使用 `<input type="number">` 手动输入模型ID，用户无法知道有哪些可用模型
- **修复:**
  - 改为 `<select>` 下拉选择，从 `modelApi.list({status:1})` 动态加载在线模型列表
  - 选项显示 `modelName (provider)` 格式，便于用户识别
  - `onMounted` 自动加载模型列表，失败时 Toast 提示
  - 验证规则 `rules.custom((v) => v > 0)` 保持不变
- **影响文件:** `AppCreateView.vue`
- **修复时间:** 2026-07-09

### 2.10 AgentFlowView.vue 模型选项从硬编码改为API动态加载
- **问题:** LLM节点配置面板的模型选项硬编码为 `GPT-4`/`GPT-3.5-Turbo`/`Claude-3-Opus` 等6个固定选项

  - 模板中 `<select>` 改为 `v-for="m in modelOptions"` 动态渲染

- **影响文件:** `AgentFlowView.vue`
- **修复时间:** 2026-07-09
