# 第一章 项目总览与战略目标

## 1.1 项目背景

基于竞品分析报告V2.0的核心发现：
- 2025年中国数据治理平台市场规模达1,927.6亿元，AI驱动型占比突破65%
- 82.7%政企客户将"信创适配+DCMM认证"作为选型首要前提
- AI治理赛道尚无专业独立产品（蓝海），现有厂商均以AI开发平台附带治理
- 无竞品同时覆盖"数据治理+AI治理+信创SaaS+独立/集成双模式"
- Salesforce 80亿美元收购Informatica验证赛道价值

## 1.2 战略目标

| 目标层级 | 目标描述 | 量化指标 | 时间节点 |
|:--------:|----------|----------|:--------:|
| **G1** | 智链先行商用，抢占AI治理蓝海 | 3-5家金融客户签约 | M6 |
| **G2** | DCMM四级认证获取 | 通过DCMM四级评估 | M6 |
| **G3** | 智赢V1.0上线，双产品集成 | 智赢V1.0发布+集成模式验证 | M12 |
| **G4** | SaaS版上线，覆盖中小企业 | SaaS平台发布+100+租户 | M18 |
| **G5** | 规模化+生态构建 | 50+私有化客户+500+SaaS租户 | M24 |
| **G6** | 年收入目标 | M6: 600万 / M12: 2000万 / M18: 3500万 / M24: 5000万+ | 按阶段 |

## 1.3 四模式交付目标

| 模式 | 交付时间 | 商业目标 |
|------|:--------:|----------|
| 模式A: 私有化·智链独立 | M6 | 首批3-5家金融客户 |
| 模式B: 私有化·集成 | M12 | 双产品组合销售 |
| 模式C: SaaS·独立 | M18 | 中小企业100+租户 |
| 模式D: SaaS·集成 | M18 | 中大企业SaaS 20+租户 |

## 1.4 关键约束

| 约束类型 | 约束内容 |
|----------|----------|
| 技术约束 | 一套代码通过Profile切换支持四模式 |
| 时间约束 | 智链M6商用 / 智赢M12上线 / SaaS M18上线 |
| 资源约束 | 初期团队48-65人，预算控制在3000万/年以内 |
| 合规约束 | DCMM四级+等保三级+国密认证 |
| 信创约束 | 全栈信创适配（详见DES-09）：多国产数据库(达梦/金仓/openGauss) + 多CPU(飞腾/鲲鹏/龙芯) + 多OS(麒麟/UOS/openEuler) + 全量国密(SM2/SM3/SM4/SM9/TLCP) + 国产中间件(TongWeb/TongMQ) + 自动适配 |
| 信创认证 | 等保2.0三级 + 国密二级密码模块认证 + DCMM四级 + 信创工委会认证 + 各厂商兼容认证(预算~94万) |

# 第十章 质量保障体系

## 10.1 质量目标

| 质量维度 | 目标 | 度量方式 |
|----------|------|----------|
| 代码质量 | 单元测试覆盖率≥80% | JaCoCo报告 |
| 代码规范 | SonarQube A级 | 静态扫描 |
| 功能质量 | P0/P1缺陷数=0 | 缺陷追踪 |
| 性能质量 | API响应<200ms(P95) | 性能测试 |
| 安全质量 | 0高危漏洞 | 安全扫描 |
| 交付质量 | Sprint按时完成率≥90% | 燃尽图 |

## 10.2 质量门禁

```
CI/CD质量门禁:

代码提交 → 单元测试(≥80%) → 代码规范(SonarQube A) → 安全扫描(0高危)
    → 集成测试(100%通过) → 构建打包 → 部署环境 → 冒烟测试
    → 任何环节失败 → 阻断合并
```

## 10.3 测试策略

| 测试类型 | 范围 | 执行频率 | 工具 |
|----------|------|:--------:|------|
| 单元测试 | 所有公共方法 | 每次提交 | JUnit 5 + Mockito |
| 集成测试 | 服务间API调用 | 每次合并 | Spring Boot Test |
| 端到端测试 | 关键业务流程 | 每Sprint | Selenium/Playwright |
| 性能测试 | API响应+并发 | 每里程碑 | JMeter |
| 安全测试 | 渗透+代码扫描 | 每里程碑 | OWASP ZAP + SonarQube |
| 兼容性测试 | 四模式切换 | 每里程碑 | 自动化脚本 |
