## 2. 安全基线管理

### 2.1 OS安全基线

| 序号 | 基线项 | 标准 | 检查方法 | 状态 |
|:----:|--------|------|---------|:----:|
| 1 | 密码复杂度 | ≥12位+大小写+数字+特殊字符 | `cat /etc/pam.d/system-auth` | ✅ |
| 2 | 密码过期 | 90天 | `chage -l` | ✅ |
| 3 | 登录失败锁定 | 5次失败锁定30分钟 | `pam_tally2` | ✅ |
| 4 | 历史密码 | 不重复最近5次 | `/etc/security/opasswd` | ✅ |
| 5 | SSH协议版本 | SSHv2 | `sshd_config` | ✅ |
| 6 | Root SSH登录 | 禁止 | `PermitRootLogin no` | ✅ |
| 7 | 空密码登录 | 禁止 | `PermitEmptyPasswords no` | ✅ |
| 8 | 超时退出 | 300秒无操作 | `TMOUT=300` | ✅ |
| 9 | 历史命令记录 | 保留1000条 | `HISTSIZE=1000` | ✅ |
| 10 | 不需要的服务 | 关闭 | `systemctl list-units` | ✅ |
| 11 | SUID/SGID | 最小化 | `find / -perm -4000` | ✅ |
| 12 | 文件权限 | 关键目录700 | `ls -la` | ✅ |
| 13 | 日志审计 | auditd运行 | `systemctl status auditd` | ✅ |
| 14 | 内核模块 | 最小化加载 | `lsmod` | ✅ |
| 15 | 时间同步 | NTP同步 | `chronyc tracking` | ✅ |

## 3. 漏洞管理

### 3.1 漏洞分级与响应

| 等级 | CVSS评分 | 响应时间 | 修复时间 | 验证 |
|:----:|:--------:|:--------:|:--------:|:----:|
| 紧急(Critical) | ≥9.0 | 立即 | ≤24小时 | 渗透测试 |
| 高危(High) | 7.0-8.9 | ≤2小时 | ≤7天 | 漏洞扫描 |
| 中危(Medium) | 4.0-6.9 | ≤8小时 | ≤30天 | 漏洞扫描 |
| 低危(Low) | <4.0 | ≤24小时 | ≤90天 | 定期检查 |

### 3.2 漏洞扫描计划

| 扫描类型 | 工具 | 频率 | 范围 | 负责人 |
|---------|------|:----:|------|--------|
| 镜像漏洞 | Trivy | 每次构建 | 全部镜像 | DevOps |
| 代码漏洞 | SonarQube | 每次提交 | 全部代码 | 开发 |
| 依赖漏洞 | Snyk/OWASP | 每日 | 全部依赖 | DevOps |
| Web漏洞 | OWASP ZAP | 每周 | Web应用 | 安全 |
| 渗透测试 | Burp Suite | 每季度 | 全系统 | 安全 |
| 基线检查 | CIS Benchmark | 每月 | 全部主机 | 安全 |
| K8s安全 | kube-bench | 每月 | K8s集群 | DevOps |

### 3.3 补丁管理流程

```
漏洞发现 → 评估等级 → 补丁获取 → 测试验证 → 审批批准 → 补丁安装 → 验证确认 → 记录归档
    │                                         │          │          │
    ↓                                         ↓          ↓          ↓
  CVSS评分                                 SIT测试     变更审批    安全扫描
  影响评估                                 UAT验证    维护窗口    基线检查
```

## 4. 数据安全与隐私保护

### 4.1 数据分级分类

| 等级 | 定义 | 示例 | 保护措施 |
|:----:|------|------|---------|
| L4-极敏感 | 核心机密 | 密钥/证书/密码 | 加密存储+访问审计+最小授权 |
| L3-敏感 | 个人隐私 | PII/PHI/PCI | 脱敏展示+加密传输+访问控制 |
| L2-内部 | 业务数据 | 业务记录/日志 | 访问控制+加密传输 |
| L1-公开 | 公开信息 | 产品文档 | 无特殊保护 |

### 4.2 数据安全措施

| 措施 | 说明 | 实现方式 | 状态 |
|------|------|---------|:----:|
| 传输加密 | HTTPS/TLS 1.3 | Nginx SSL + 内部mTLS | ✅ |
| 存储加密 | 数据库TDE | DM8透明数据加密 | ✅ |
| 备份加密 | 备份文件加密 | AES-256加密 | ✅ |
| 脱敏展示 | 敏感数据脱敏 | 动态脱敏+静态脱敏 | ✅ |
| 国密算法 | SM2/SM3/SM4 | 国密证书+签名+加密 | ✅ |
| 数据防泄漏 | DLP | 内容安全检测+出水检测 | ✅ |
| 访问审计 | 全操作记录 | 审计服务+操作日志 | ✅ |
| 数据留存 | 分级留存 | 按法规配置留存策略 | ✅ |
| 数据销毁 | 安全删除 | 多次覆写+验证 | ✅ |

## 6. 安全事件响应

### 6.1 事件分级

| 级别 | 定义 | 示例 | 响应 |
|:----:|------|------|------|
| S1-严重 | 数据泄露/系统被控 | 数据库被拖库 | 立即响应+CTO通报 |
| S2-高危 | 入侵尝试/权限提升 | 提权攻击被检测 | 30分钟响应+隔离 |
| S3-中危 | 异常行为/策略违规 | 越权访问尝试 | 2小时响应+调查 |
| S4-低危 | 安全告警/配置异常 | 弱密码告警 | 8小时处理 |

### 6.2 响应流程

```
发现 → 评估 → 隔离 → 取证 → 根除 → 恢复 → 复盘
  │       │      │      │      │      │      │
  ↓       ↓      ↓      ↓      ↓      ↓      ↓
 告警    分级   断网    日志   修复   验证   报告
 用户    通知   封锁    镜像   补丁   恢复   改进
 报告    组队   账号    内存   加固   服务   更新
```
