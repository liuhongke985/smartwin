## 1. 项目概述

### 1.1 项目信息

| 项目 | 内容 |
|------|------|
| **项目名称** | SmartWin AI治理平台 (智数 + 智链) |
| **项目周期** | Sprint 1 ~ Sprint 18 (2026-01 ~ 2026-07) |
| **项目团队** | 后端开发×5, 前端开发×2, AI工程师×1, 测试×2, DevOps×1 |
| **总工时** | 约 450 人天 |
| **Sprint数** | 18个Sprint (每Sprint 2周) |

### 1.2 项目目标

构建一个集数据治理（智数）和AI运营管理（智链）于一体的企业级平台，支持私有化部署和SaaS多租户两种交付模式，满足等保三级安全合规要求，适配信创环境。

## 4. 技术架构总结

### 4.1 技术栈

| 层面 | 技术选型 |
|------|---------|
| 后端框架 | Spring Boot 3 + Spring Cloud + MyBatis-Plus |
| 前端框架 | Vue 3 + TypeScript + Element Plus + ECharts |
| AI框架 | LangChain4j (Java) + FastAPI (Python) |
| 数据库 | MySQL 8 / 达梦DM8 / 人大金仓 |
| 缓存 | Redis 7 (Cluster模式) |
| 搜索引擎 | Elasticsearch 8 |
| 图数据库 | Neo4j 5 |
| 消息队列 | RabbitMQ / RocketMQ |
| 容器编排 | Docker + Kubernetes (Helm) |
| 服务网格 | Istio (mTLS + 可观测性) |
| 监控告警 | Prometheus + Grafana + Loki + Alertmanager |
| 安全 | JWT + BCrypt + SM2/SM3/SM4 + XSS防护 + 限流 |

### 4.2 架构亮点

1. **四种交付模式**：私有化(智链/智数独立) + SaaS(智链独立/智赢集成)
2. **信创全栈适配**：达梦DM8 + 国密SM2/SM3/SM4 + ARM64
3. **AIOps智能运维**：AI告警分析 + SQL优化 + 日志分析 + 容量预测 + 异常检测
4. **多租户SaaS**：行级租户隔离 + 配额管理 + 计量计费
5. **灰度发布**：Gateway Filter + Nacos + Istio VirtualService
6. **全链路可观测**：Prometheus指标 + Loki日志 + Jaeger追踪
