## 一、集成测试概述

### 1.1 测试目标

验证各微服务间的接口调用、消息通信、数据一致性是否符合设计规范。

### 1.2 测试范围

| 集成场景 | 涉及服务 | 优先级 |
|---------|---------|:------:|
| 认证授权集成 | Gateway→Auth→Security | P0 |
| 数据目录集成 | Catalog→Metadata→Search | P0 |
| 质量检测集成 | Quality→Catalog→Notification | P0 |
| 安全审计集成 | Security→Audit→Notification | P0 |
| AI搜索集成 | AI→Catalog→Metadata | P0 |
| ETL执行集成 | ETL→Catalog→Quality→Audit | P1 |
| 数据编织集成 | Fabric→Catalog→Metadata | P1 |
| AI Agent集成 | Agent→Catalog→Quality→Security | P1 |
| AutoOps集成 | Ops→All Services | P1 |
