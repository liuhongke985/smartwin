## 1. 测试概述

### 1.1 测试目标
验证各微服务间接口调用、前后端联调、消息通信、数据一致性是否符合设计规范。

### 1.2 测试环境

| 组件 | 配置 | 说明 |
|------|------|------|
| Docker Compose | 全量 35 容器 | 与生产环境一致 |
| 数据库 | MySQL 8.0 + DM8 | 双数据库验证 |
| Redis | 7.0 | Token缓存 + Dashboard聚合缓存 |
| Kafka | 3 节点 | 消息队列测试 |
| Nginx | 网关 | API 路由 + 负载均衡 |
