## 3. 单元测试规范

### 3.1 Java单元测试

| 项目 | 说明 |
|------|------|
| 框架 | JUnit 5 + Mockito |
| 断言 | AssertJ |
| 覆盖率工具 | JaCoCo |
| 覆盖率要求 | 行覆盖≥70%，分支覆盖≥60% |

```java
@ExtendWith(MockitoExtension.class)
class ModelServiceTest {
    @Mock
    private ModelMapper modelMapper;
    @InjectMocks
    private ModelServiceImpl modelService;

    @Test
    @DisplayName("创建模型 - 名称重复时抛出异常")
    void createModel_duplicateName_throwsException() {
        // Given
        when(modelMapper.selectByName("GPT-4")).thenReturn(Optional.of(existingModel));
        ModelCreateRequest request = new ModelCreateRequest();
        request.setModelName("GPT-4");

        // When & Then
        assertThatThrownBy(() -> modelService.createModel(request))
            .isInstanceOf(BusinessException.class)
            .hasMessageContaining("模型名称已存在");
    }
}
```

## 8. 测试缺陷管理

### 8.1 缺陷分级

| 等级 | 定义 | 修复时限 |
|:----:|------|:--------:|
| P0-致命 | 系统崩溃/数据丢失/核心功能不可用 | 立即 |
| P1-严重 | 主要功能不可用/数据错误 | 24h |
| P2-一般 | 次要功能问题/体验问题 | 3天 |
| P3-轻微 | 界面瑕疵/建议优化 | 下Sprint |

### 8.2 缺陷生命周期

```
新建 → 分配 → 修复 → 验证 → 关闭
  │                 │
  └──拒绝 ←─────────┘
  
  新建 → 重复 → 关闭
  新建 → 延期 → 重新打开
```
