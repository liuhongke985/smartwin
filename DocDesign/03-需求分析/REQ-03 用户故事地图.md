## 一、用户故事地图概述

### 1.1 目的

本文档以用户故事地图形式，按用户角色和业务流程组织SmartWin智赢平台平台全部用户故事，为迭代规划和开发优先级提供依据。

### 1.2 用户角色

| 角色编号 | 角色名称 | 职责描述 | 权限级别 |
|:--------:|---------|---------|:--------:|
| R-01 | 数据管理员 | 数据资产注册、目录管理、标准制定 | 管理员 |
| R-02 | 数据分析师 | 数据探索、报表分析、AI建模 | 高级用户 |
| R-03 | 业务用户 | 数据查询、报表查看、数据申请 | 普通用户 |
| R-04 | 安全管理员 | 分类分级、脱敏规则、安全审计 | 管理员 |
| R-05 | AI工程师 | 模型管理、Agent配置、Prompt管理 | 高级用户 |
| R-06 | 运维管理员 | 系统配置、监控告警、AutoOps | 管理员 |
| R-07 | 管理层 | 数据资产看板、价值评估、决策支持 | 决策者 |

### 1.3 故事地图结构

```
                    行业方案层    通用平台层    基础设施层
                    ┌──────┐     ┌──────┐     ┌──────┐
   数据治理主线 ──→  │ 金融  │     │数据目录│     │认证授权│
                    │ 政务  │     │元数据 │     │系统管理│
                    │ 制造  │     │数据质量│     │安全治理│
                    │ 医疗  │     │数据标准│     │审计日志│
                    └──────┘     │数据血缘│     │信创适配│
                                 │ETL引擎│     └──────┘
   AI智能主线  ──→               │数据编织│
                                 │AI搜索 │
                                 │AI问答 │
                                 │AI Agent│
                                 └──────┘
   安全合规主线 ──→              国密+国密+零信任+等保三级
   运营运维主线 ──→              AutoOps+监控告警+容量管理
```
