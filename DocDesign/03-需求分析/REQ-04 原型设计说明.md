## 一、原型设计概述

### 1.1 设计目标

为SmartWin智赢平台平台提供完整的界面原型设计方案，确保开发团队、产品团队和客户对系统界面有统一认知，降低开发返工率。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **AI优先** | AI能力以自然的方式融入交互流程，而非独立功能模块 |
| **信创适配** | 界面兼容国产浏览器和操作系统，不依赖海外前端特性 |
| **多端一致** | 桌面端、平板端、移动端视觉和交互统一 |
| **无障碍** | 支持键盘导航、屏幕阅读器、高对比度模式 |
| **国际化** | 支持中英文双语，预留多语言扩展 |

### 1.3 设计工具与规范

| 项目 | 工具/规范 |
|------|----------|
| 原型工具 | Figma / 墨刀 |
| 设计系统 | 自研品牌设计系统（Brand Design System） |
| 图标库 | Lucide Icons + 自定义行业图标 |
| 字体 | 思源黑体 / Noto Sans SC / Inter |
| 色彩规范 | 品牌主色 #1890FF，信创蓝 #0052D9 |
| 间距规范 | 4px基准网格系统 |

## 三、核心页面原型说明

### 3.1 工作台（Dashboard）

#### 3.1.1 数据概览页

| 区域 | 内容 | 交互说明 |
|------|------|---------|
| 顶部栏 | Logo + 全局搜索 + 通知 + 用户头像 | 全局搜索支持AI自然语言搜索 |
| 左侧导航 | 多级菜单树 | 可折叠，支持收藏常用功能 |
| KPI卡片行 | 数据资产总数/质量分/活跃用户/告警数 | 点击卡片钻取详情 |
| 数据趋势图 | 数据增长/质量趋势/使用趋势 | 支持时间范围切换 |
| 任务待办区 | 我的待办/审批/任务 | 支持快速处理 |
| 告警通知区 | 安全/质量/系统告警 | 分级展示，支持一键处理 |

#### 3.1.2 AI Copilot侧边栏

| 功能 | 说明 |
|------|------|
| 唤起方式 | 右下角浮动按钮 / 快捷键 Ctrl+K |
| 对话界面 | 聊天式交互，支持多轮对话 |
| 上下文感知 | 根据当前页面提供上下文建议 |
| 快捷操作 | AI推荐操作 + 一键执行 |
| 数据问答 | 自然语言查询数据，返回图表+表格 |

## 四、交互设计规范

### 4.1 全局交互模式

| 交互模式 | 说明 | 应用场景 |
|---------|------|---------|
| AI Copilot | 全局AI助手侧边栏 | 所有页面 |
| 快捷搜索 | Ctrl+K唤起全局搜索 | 所有页面 |
| 批量操作 | 表格多选+批量操作栏 | 列表页 |
| 拖拽排序 | 拖拽调整顺序/布局 | 看板/ETL设计器 |
| 右键菜单 | 上下文操作菜单 | 表格/图表 |
| 快捷键 | 高频操作快捷键 | 所有页面 |
| 实时通知 | WebSocket推送通知 | 全局通知栏 |

### 4.2 AI交互规范

| 场景 | 交互方式 | 说明 |
|------|---------|------|
| AI搜索 | 自然语言输入 | 支持模糊匹配+语义搜索 |
| AI问答 | 聊天式对话 | 多轮对话，上下文记忆 |
| AI建议 | 内联建议卡片 | 在操作流程中提供AI建议 |
| AI执行 | 确认后执行 | AI操作需用户确认 |
| AI解释 | 可展开解释 | XAI展示决策依据 |
