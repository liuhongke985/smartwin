## 一、数据需求概述

### 1.1 数据源需求

| 数据源类型 | 具体数据源 | 接入方式 | 数据量级 | 优先级 |
|-----------|-----------|---------|---------|:------:|
| 关系型数据库 | MySQL/PostgreSQL/Oracle/达梦DM8/人大金仓 | JDBC/CDC | TB级 | P0 |
| 大数据平台 | Hive/HBase/ClickHouse/Doris | SQL/SDK | PB级 | P0 |
| 文件系统 | CSV/JSON/Parquet/Excel/XML | 批量导入 | GB-TB级 | P0 |
| 消息队列 | Kafka/RocketMQ/RabbitMQ | 流式订阅 | 实时 | P0 |
| API接口 | RESTful/GraphQL/gRPC | 定时拉取/Webhook | 按需 | P1 |
| NoSQL | MongoDB/Redis/Elasticsearch | SDK | TB级 | P1 |
| 云存储 | S3/OSS/HDFS | SDK | PB级 | P1 |
| IoT设备 | MQTT/CoAP | 流式订阅 | 实时 | P2 |

### 1.2 数据分类

| 数据分类 | 数据内容 | 敏感级别 | 存储策略 |
|---------|---------|:--------:|---------|
| 元数据 | 表结构、字段信息、索引信息 | 低 | 永久存储 |
| 业务数据 | 客户数据、交易数据、日志数据 | 高 | 按生命周期管理 |
| 质量数据 | 质量规则、检测结果、质量报告 | 中 | 保留2年 |
| 安全数据 | 审计日志、安全告警、权限记录 | 高 | 永久存储（不可篡改） |
| AI数据 | 模型参数、训练数据、推理结果 | 中 | 按模型版本管理 |
| 配置数据 | 系统配置、用户偏好、角色权限 | 低 | 永久存储 |

## 二、数据模型需求

### 2.1 核心实体模型

| 实体 | 说明 | 关键属性 | 关系 |
|------|------|---------|------|
| 数据源 | 数据来源定义 | 类型/连接信息/认证 | 1:N 数据集 |
| 数据集 | 数据资产单元 | 名称/描述/字段/分类 | N:1 数据源, 1:N 数据字段 |
| 数据字段 | 字段元数据 | 名称/类型/描述/敏感级别 | N:1 数据集 |
| 质量规则 | 数据质量检测规则 | 类型/表达式/阈值 | N:N 数据集 |
| 质量结果 | 质量检测结果 | 规则ID/检测时间/结果/状态 | N:1 质量规则 |
| 数据标准 | 数据规范定义 | 编码/名称/类型/范围 | N:N 数据字段 |
| 血缘关系 | 数据流转关系 | 源节点/目标节点/类型 | 图结构 |
| 分类分级 | 安全分类分级 | 分类/级别/规则 | N:N 数据集 |
| 脱敏规则 | 数据脱敏配置 | 类型/算法/参数 | N:N 数据字段 |
| 用户 | 系统用户 | ID/名称/角色/组织 | N:N 角色 |
| 角色 | 权限角色 | 名称/权限/范围 | N:N 权限 |
| 审计日志 | 操作审计 | 用户/操作/时间/对象 | 独立存储 |

## 三、数据存储需求

### 3.1 存储架构

| 存储类型 | 技术 | 用途 | 容量规划 | 性能要求 |
|---------|------|------|---------|---------|
| 关系型 | PostgreSQL/达梦DM8 | 业务数据、配置数据 | 5TB | 读写<10ms |
| 时序数据库 | InfluxDB/TDengine | 监控数据、IoT数据 | 20TB | 写入>100K/s |
| 图数据库 | Neo4j | 数据血缘、关系网络 | 500GB | 查询<100ms |
| 搜索引擎 | Elasticsearch | 全文搜索、日志 | 10TB | 搜索<50ms |
| 缓存 | Redis | 热数据缓存、会话 | 100GB | 读写<1ms |
| 对象存储 | MinIO/S3 | 文件、附件、影像 | 50TB | 上传<5s |
| 列式存储 | ClickHouse | 分析查询、报表 | 30TB | 查询<1s |
| 消息队列 | Kafka | 实时数据流 | — | 吞吐>1M/s |

### 3.2 数据分区与分片策略

| 数据类型 | 分区策略 | 分片策略 | 保留周期 |
|---------|---------|---------|---------|
| 审计日志 | 按月分区 | 按用户ID哈希 | 永久 |
| 质量结果 | 按月分区 | 按规则ID哈希 | 2年 |
| 监控数据 | 按天分区 | 按服务名分片 | 90天 |
| 交易数据 | 按月分区 | 按交易号哈希 | 10年 |
| ETL日志 | 按天分区 | 按任务ID分片 | 180天 |

## 四、数据质量需求

### 4.1 质量维度

| 维度 | 定义 | 检测方法 | 目标值 |
|------|------|---------|:------:|
| 完整性 | 数据无缺失 | 空值检测/行数比对 | ≥99% |
| 准确性 | 数据正确无误 | 规则校验/交叉比对 | ≥98% |
| 一致性 | 跨系统数据一致 | 一致性规则/比对 | ≥95% |
| 及时性 | 数据按时更新 | 延迟监控/SLA | ≤5分钟 |
| 唯一性 | 数据无重复 | 去重检测/主键校验 | 100% |
| 有效性 | 数据符合规范 | 格式校验/范围校验 | ≥99% |

### 4.2 质量规则分类

| 规则类型 | 规则数 | 说明 |
|---------|:------:|------|
| 完整性规则 | 45 | 非空检查、行数检查 |
| 准确性规则 | 38 | 范围检查、引用检查 |
| 一致性规则 | 25 | 跨表/跨系统比对 |
| 唯一性规则 | 20 | 主键/唯一键检查 |
| 有效性规则 | 28 | 格式/枚举值检查 |
| **合计** | **156** | 覆盖4大行业 |

## 五、数据安全需求

### 5.1 分类分级标准

| 级别 | 名称 | 说明 | 安全措施 |
|:----:|------|------|---------|
| L4 | 极高 | 核心机密数据 | 国密加密+国密安全+严格访问控制 |
| L3 | 高 | 敏感个人信息 | 加密+脱敏+访问审计 |
| L2 | 中 | 业务数据 | 访问控制+审计 |
| L1 | 低 | 公开数据 | 基本访问控制 |

### 5.2 脱敏需求

| 数据类型 | 脱敏算法 | 应用场景 |
|---------|---------|---------|
| 手机号 | 中间4位掩码 | 展示/导出 |
| 身份证 | 中间8位掩码 | 展示/导出 |
| 银行卡 | 仅留后4位 | 展示/导出 |
| 姓名 | 姓+** | 展示/导出 |
| 地址 | 部分掩码 | 展示/导出 |
| 金额 | 范围替换 | 分析/统计 |
