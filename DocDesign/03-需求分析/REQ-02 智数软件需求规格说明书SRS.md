## 1 引言

### 1.1 目的

本文档定义智数（SmartData）AI原生数据治理平台的软件需求规格，覆盖功能需求、非功能需求、接口需求和约束条件。智数是“智赢”集成平台的两个独立可售产品之一，专注于企业级AI原生数据治理。

### 1.2 范围

智数平台涵盖以下数据治理核心域：
- 数据资产管理（目录/编目/搜索/评估）
- 元数据管理（技术/业务/管理元数据）
- 数据质量管理（规则/检测/报告/修复）
- 数据标准管理（标准定义/映射/落地）
- 数据血缘分析（采集/可视化/影响分析）
- 主数据管理（MDM建模/分发/治理）
- 数据生命周期管理（归档/销毁/留存）
- 数据服务管理（API发布/授权/监控）

### 1.3 术语

| 术语 | 说明 |
|------|------|
| 智数 (SmartData) | AI原生数据治理独立产品，集成于智赢平台 |
| 智链 (SmartChain) | AI模型治理与监控独立产品，与智数共同构成智赢 |
| 智赢 (SmartWin) | 智数+智链集成平台 |
| 数据资产 | 企业中具有潜在价值的数据资源 |
| 元数据 | 描述数据的数据（技术/业务/管理） |
| 数据血缘 | 数据从产生到消费的流转路径 |
| 数据质量 | 数据满足业务要求的程度 |

## 2 总体描述

### 2.1 产品定位

智数定位为AI原生数据治理平台，帮助客户实现“数据可见、数据可懂、数据可信、数据可用”四大目标。

### 2.2 用户角色

| 角色 | 说明 | 核心场景 |
|------|------|---------|
| 数据治理管理员 | 全局管理 | 配置标准/规则/流程/权限 |
| 数据资产管理员 | 资产管理 | 数据编目/分类/评估/发布 |
| 数据质量工程师 | 质量管控 | 质量规则配置/检测/报告 |
| 元数据管理员 | 元数据管理 | 元模型定义/采集/维护 |
| 业务分析师 | 数据分析 | 血缘分析/影响评估 |
| 数据消费者 | 数据使用 | 搜索/申请/使用数据服务 |

### 2.3 运行环境

| 项目 | 要求 |
|------|------|
| OS | Linux (CentOS 7+/麒麟V10/统信UOS/openEuler) |
| JDK | OpenJDK 17+ |
| 数据库 | MySQL 8.0+ / 达梦DM8 / 人大金仓 / openGauss |
| 缓存 | Redis 7.0+ |
| 搜索 | Elasticsearch 8.x |
| 图数据库 | Neo4j 5.x |
| 浏览器 | Chrome 100+/Edge 100+/Firefox 100+ |

## 6 约束条件

1. **信创合规**: 必须通过信创环境认证，支持国产CPU/OS/数据库/国密算法
2. **独立可售**: 智数必须能独立部署运行，不依赖智链
3. **集成兼容**: 与智链集成时需支持SSO、数据互通、统一菜单
4. **数据安全**: 满足等保2.0三级要求
5. **技术栈**: 后端 Spring Boot 3.2.5 + MyBatis-Plus 3.5.7，前端 Vue 3 + Vite
