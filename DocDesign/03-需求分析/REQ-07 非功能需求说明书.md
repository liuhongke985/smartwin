## 二、可用性需求

### 2.1 可用性目标

| 级别 | SLA目标 | 年停机时间 | 适用模块 |
|:----:|:-------:|:---------:|---------|
| L1 | 99.99% | ≤52.6分钟 | 核心服务（认证/网关/审计） |
| L2 | 99.9% | ≤8.76小时 | 业务服务（目录/质量/安全） |
| L3 | 99.5% | ≤43.8小时 | 辅助服务（报表/分析） |

### 2.2 容错策略

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| 多副本 | 数据3副本，服务多实例 | 所有核心服务 |
| 故障转移 | 自动故障检测+转移 | 数据库/消息队列 |
| 熔断降级 | 错误率超阈值自动降级 | 依赖服务调用 |
| 限流保护 | 超过阈值自动限流 | API网关 |
| 自愈恢复 | AutoOps自动恢复 | V2.0+ |
| 灰度发布 | 新版本灰度切换 | 所有发布 |

### 2.3 RTO/RPO

| 场景 | RTO | RPO | 方案 |
|------|:---:|:---:|------|
| 单节点故障 | ≤30s | 0 | 自动故障转移 |
| 单可用区故障 | ≤5分钟 | ≤1分钟 | 跨AZ部署 |
| 数据中心故障 | ≤30分钟 | ≤5分钟 | 异地灾备 |
| 数据误删 | ≤1小时 | ≤15分钟 | 快照恢复+binlog |

## 三、安全需求

### 3.1 认证授权

| 需求项 | 要求 |
|--------|------|
| 认证方式 | JWT + OAuth2.0 + SSO |
| 密码策略 | ≥12位，大小写+数字+特殊字符，90天过期 |
| 多因素认证 | 管理员强制MFA |
| 会话管理 | 超时30分钟，单设备登录 |
| 权限模型 | RBAC + ABAC + 数据级权限 |
| API认证 | JWT + 接口签名 |

### 3.2 加密需求

| 需求项 | 要求 |
|--------|------|
| 传输加密 | TLS 1.3 / TLCP（国密） |
| 存储加密 | AES-256 / SM4 |
| 密码哈希 | BCrypt / SM3 |
| 密钥管理 | KMS + 密钥轮换 |
| 国密安全 | NIST PQC + QKD（V2.0+） |

### 3.3 合规需求

| 合规标准 | 要求 |
|---------|------|
| 等保三级 | 身份鉴别/访问控制/安全审计/入侵防范/数据完整性/保密性 |
| 数据安全法 | 数据分类分级/风险评估/安全保护/数据跨境 |
| 个人信息保护法 | 最小必要/告知同意/去标识化/安全评估 |
| 密码法 | 国密算法应用/密码评估 |
| ISO 27001 | 信息安全管理体系 |
