## 一、培训概述

### 1.1 培训目标

| 目标 | 说明 |
|------|------|
| 快速上手 | 用户能在培训后独立使用系统核心功能 |
| 深度掌握 | 管理员能独立进行系统配置和运维 |
| 最佳实践 | 传递数据治理和AI应用的最佳实践 |
| 自主学习 | 建立在线学习资源，支持自主学习 |

### 1.2 培训对象

| 角色 | 培训内容 | 课时 | 方式 |
|------|---------|:----:|------|
| 最终用户 | 系统基本操作+AI搜索问答 | 4h | 线下/线上 |
| 数据管理员 | 数据治理全流程+配置管理 | 8h | 线下 |
| 安全管理员 | 安全合规+审计+国密配置 | 6h | 线下 |
| AI工程师 | AI Agent编排+模型管理 | 8h | 线下 |
| 运维管理员 | AutoOps+监控告警+故障处理 | 6h | 线下 |
| 系统管理员 | 用户管理+系统配置+备份恢复 | 4h | 线下 |

---

## 二、培训计划

### 2.1 培训日程

| 阶段 | 时间 | 内容 | 对象 |
|:----:|:----:|------|------|
| 第1天 | 上午 | 系统概览+工作台+AI Copilot | 全体用户 |
| 第1天 | 下午 | 数据目录+元数据管理 | 数据管理员 |
| 第2天 | 上午 | 数据质量+数据血缘+数据标准 | 数据管理员 |
| 第2天 | 下午 | 安全合规+分类分级+脱敏 | 安全管理员 |
| 第3天 | 上午 | AI搜索+AI问答+AI Agent编排 | AI工程师 |
| 第3天 | 下午 | AutoOps+监控告警+故障处理 | 运维管理员 |
| 第4天 | 上午 | 系统管理+配置+备份恢复 | 系统管理员 |
| 第4天 | 下午 | 综合演练+考核+答疑 | 全体 |

### 2.2 培训材料

| 材料 | 说明 | 状态 |
|------|------|:----:|
| 培训PPT | 分角色培训课件 | ✅ |
| 操作手册 | 图文操作指南 | ✅ |
| 视频教程 | 录制操作演示视频 | ✅ |
| 练习题库 | 分角色练习题 | ✅ |
| 考核试卷 | 培训考核试题 | ✅ |
| 在线帮助 | 系统内置帮助文档 | ✅ |

## 三、考核认证

### 3.1 考核标准

| 角色 | 笔试 | 实操 | 通过标准 |
|------|:----:|:----:|---------|
| 最终用户 | 20题 | 3个场景 | ≥80分 |
| 数据管理员 | 30题 | 5个场景 | ≥85分 |
| 安全管理员 | 25题 | 4个场景 | ≥85分 |
| AI工程师 | 30题 | 5个场景 | ≥85分 |
| 运维管理员 | 25题 | 4个场景 | ≥85分 |
| 系统管理员 | 20题 | 3个场景 | ≥80分 |

### 3.2 认证体系

| 认证级别 | 要求 | 有效期 |
|---------|------|:------:|
| 初级用户 | 完成基础培训+考核通过 | 2年 |
| 高级用户 | 完成进阶培训+实操考核 | 2年 |
| 认证管理员 | 完成全套培训+综合考核 | 2年 |
| 认证讲师 | 通过讲师认证+授课评估 | 3年 |
