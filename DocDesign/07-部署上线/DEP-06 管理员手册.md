## 一、系统管理

### 1.1 用户管理

| 操作 | 路径 | 说明 |
|------|------|------|
| 创建用户 | 系统管理 > 用户管理 > 新增 | 设置用户名/姓名/邮箱/角色 |
| 编辑用户 | 用户列表 > 编辑 | 修改用户信息/状态 |
| 重置密码 | 用户列表 > 重置密码 | 管理员重置用户密码 |
| 启用/禁用 | 用户列表 > 启用/禁用 | 控制用户登录权限 |
| 批量导入 | 用户管理 > 批量导入 | Excel模板批量导入 |

### 1.2 角色权限

| 操作 | 说明 |
|------|------|
| 创建角色 | 定义角色名称和权限范围 |
| 权限分配 | 按模块/功能分配操作权限 |
| 数据权限 | 设置数据访问范围（部门/数据集级别） |
| 角色继承 | 支持角色继承关系 |

### 1.3 组织管理

## 五、备份与恢复

### 5.1 备份策略

| 数据类型 | 备份频率 | 保留周期 | 备份方式 |
|---------|---------|---------|---------|
| 业务数据 | 每日 | 30天 | 全量+增量 |
| 审计日志 | 每日 | 永久 | 归档存储 |
| 配置数据 | 实时 | 90天 | 版本控制 |
| 文件存储 | 每日 | 90天 | 增量同步 |

### 5.2 恢复流程

```
1. 确认恢复范围 → 2. 停止相关服务 → 3. 恢复数据备份
→ 4. 验证数据完整性 → 5. 重启服务 → 6. 通知用户
```
