## 2. 发布概述

SmartWin V1.0.0 是智赢平台的首次商用发布版本，包含以下四大子系统：

| 子系统 | 说明 | 商用就绪度 |
|--------|------|:----------:|
| 智链(SmartChain) | AI运营管理平台，含AI模型管理、智能体应用、Agent编排、成本管控、风险评估、提示词管理 | 96/100 |
| 智数(SmartData) | AI原生数据治理平台，含数据目录、元数据、血缘、质量、标准、主数据、生命周期、数据服务 | 94/100 |
| 智赢平台(SmartWin) | 共享平台服务，含认证、系统管理、安全、审计、配置、通知、仪表盘 | 88/100 |
| 运营推广平台 | 内容营销、SEO/GEO、官网门户、博客CMS、SaaS运营 | 95/100 |
| **整体** | | **93/100** |

## 3. 新增功能

### 3.1 智链(SmartChain) — 69个Vue页面，~81个API

- AI模型管理：模型CRUD、版本管理、API Key管理、模型对比、统计、测试
- 智能体应用：应用CRUD、聊天对话、发布、统计、设置、分类、收藏
- Agent编排：Agent CRUD、工具管理、流程编排、日志、版本管理
- 成本管理：成本总览、记录、预算、告警、报告、分析
- 风险评估：风险概览、规则、事件、报告、处理、趋势
- 提示词管理：提示词库、编辑器、版本、测试、分类
- 系统管理：用户/角色/权限/组织/字典/日志/设置/变更日志
- 内容营销：博客系统、案例展示、SEO/GEO、中英文官网

### 3.2 智数(SmartData) — 18个Vue页面，~125个API

- 数据目录：资产注册、分类、搜索、详情、关联资产
- 元数据管理：元数据CRUD、自动采集、技术/业务元数据
- 数据血缘：血缘图谱、上下游分析、影响分析、自动布局
- 数据质量：质量规则、质量报告、预测预警、评分卡
- 业务术语表：术语CRUD、分类管理、批量导入
- 数据标准：标准CRUD、标准分类、批量导入导出
- 主数据管理：主数据CRUD、去重、审批
- 数据生命周期：策略CRUD、归档、销毁
- 数据服务：API发布、API测试、订阅管理
- AI智能搜索：自然语言查询、智能推荐
- AI智能标注：自动标注、人工复核、标注训练

### 3.3 智赢平台(SmartWin) — 7个Java微服务，~114个API

- 认证服务：JWT认证、OAuth2、RBAC权限、多租户
- 系统管理：用户/角色/权限/字典/租户/计费/SaaS运营
- 安全服务：安全策略、零信任引擎、速率限制
- 审计服务：操作日志、审计追踪
- 配置服务：动态配置、灰度发布
- 通知服务：邮件/短信/站内通知
- 仪表盘服务：聚合数据、AI运维、联邦学习

### 3.4 运营推广平台 — 8个Vue页面，~60个API

- 运营大盘、计费管理、增长指标、功能开关
- 研讨会管理、渠道合作、邮件营销、推荐计划
- NPS/CSAT调研、博客CMS、社区运营
